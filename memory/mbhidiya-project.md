Projet de creation du site web de **Mbhidiya Intelligence**, firme d'intelligence economique et d'investigations specialisee dans le corridor Canada-Afrique.

**Why:** L'entreprise a besoin d'un site vitrine professionnel pour ses services d'intelligence, due diligence et investigations cross-border. Le site sera presente a l'entreprise pour discussion.

**How to apply:** Le brief complet est dans `Mbhidiya_New_Website_Text.docx.pdf` (28 pages). Le logo est dans `Screenshot_20260712_215626_WhatsApp.jpg`.

## Etat d'avancement

- Phase reflexion UX/UI : **TERMINEE** (12 documents dans `docs/`)
  - Analyse entreprise, charte graphique, identite visuelle, typographie, palette couleurs, composants UI, architecture info, wireframes, principes UX, choix techno Symfony, suggestions, audit UX
- Prochaines etapes : compiler en DOCX, discuter avec l'entreprise, puis demarrer le dev Symfony

## Decisions cles prises

- **Stack technique** : Symfony 7.x + Twig + Doctrine + EasyAdmin + SCSS + Stimulus
- **Typographie** : DM Serif Display (titres) + Inter (corps)
- **Couleur dominante** : Navy #0C1B3A (pas les couleurs panafricaines qui restent en accent)
- **Navigation** : 6 items (Services | A propos | Canada & Afrique | Secteurs | Insights | [Contact CTA])
- **11 services** du PDF respectes, organises en 3 categories
- **15 lois UX** auditees et respectees
