# 03 - Identite Visuelle

## 1. Vision de l'identite

L'identite visuelle de Mbhidiya Intelligence doit incarner un concept central :

> **La clarte qui emerge de la complexite.**

Mbhidiya travaille dans des environnements opaques (structures de propriete complexes, reseaux d'influence caches, marches emergents a l'information fragmentee) et en extrait de la clarte pour ses clients. L'identite visuelle doit refleter ce parcours : de l'obscurite vers la lumiere, du flou vers la nettete, du bruit vers le signal.

## 2. Analyse du logo existant

### Decodage symbolique

Le logo de Mbhidiya contient une richesse symbolique deliberee :

**Les trois arcs concentriques (rouge, vert, or)**

- Reference directe aux couleurs panafricaines, ancrant l'entreprise dans son contexte geographique
- La disposition en arcs concentriques evoque des couches de protection / d'investigation : chaque couche represente un niveau de profondeur dans l'analyse
- L'ouverture des arcs (non fermes) suggere un processus en mouvement, une investigation en cours

**L'element orbital central (bleu marine)**

- Represente un oeil stylise : la capacite d'observation, l'intelligence
- Les orbites circulaires evoquent les connexions, les reseaux, les relations entre entites
- Le point central represente le sujet d'investigation, le noyau de verite que Mbhidiya cherche a atteindre
- Le bleu marine apporte la dimension corporate, la confiance, la profondeur

**Le logotype**

- "Mbhidiya" en serif bold : ancrage, autorite, permanence
- "INTELLIGENCE" en sans-serif espace : modernite, precision, technicite

### Couleurs du logo et leur signification dans le contexte de la marque

| **Rouge**       | Sang verse, lutte          | Risque, alertes, ce qui doit attirer l'attention |

## 3. Langage visuel du site web

### Principe directeur : "Layers of Intelligence"

Le design du site utilise le concept de **couches superposees** comme metaphore visuelle du travail d'investigation de Mbhidiya :

**Couche 1 - Surface (ce que tout le monde voit)**

- Fond clair (`#FFFFFF` / `#F7F8FA`)
- Contenu principal, titres, texte
- Represente l'information publiquement disponible

**Couche 2 - Profondeur (ce que Mbhidiya revele)**

- Fond navy (`#0C1B3A` / `#1A3158`)
- Sections de mise en avant, CTAs, hero
- Represente l'intelligence cachee, la profondeur de l'analyse

**Couche 3 - Connexions (les liens invisibles)**

- Elements graphiques subtils : lignes de reseau en arriere-plan, noeuds connectes
- Opacite faible (5-15%), jamais intrusif
- Represente les reseaux et relations que Mbhidiya cartographie

### Alternance des sections

La page type alterne entre fond clair et fond sombre selon un rythme qui maintient l'engagement :

```
[HERO - Navy Gradient - impact maximal]
[Section - Fond clair - contenu principal]
[Section - Fond navy - mise en avant / citation / stats]
[Section - Fond clair - services / details]
[Section - Fond Off-White - temoignages / process]
[CTA - Navy Gradient - appel a l'action]
[Footer - Near Black - informations pratiques]
```

## 4. Elements graphiques recurrents

### 4.1 La ligne de connexion (Network Line)

Element graphique signature de la marque : une fine ligne (`1px`, `#1E3A6E` a 10-20% d'opacite) qui relie des points nodaux. Utilisee en arriere-plan des sections pour evoquer les reseaux d'investigation.

**Specifications** :

- Epaisseur : 1px
- Couleur : `#1E3A6E` avec opacite entre 8% et 20%
- Points nodaux : cercles de 4-6px de diametre
- Animation : aucune (statique) ou tres lent mouvement de pulsation (> 4s)
- Densite : espacee, jamais surchargee. Maximum 8-12 noeuds visibles par section.

### 4.2 L'arc d'accent

Reprise de la forme des arcs du logo, utilisee comme element decoratif :

- En arriere-plan de sections (tres grande echelle, faible opacite 3-5%)
- Comme separateur graphique entre sections
- En accent derriere les photos de l'equipe

### 4.3 Le trait dore (Gold Accent Line)

Un trait fin (2-3px) en `#D4A017` utilise de maniere tres parcimonieuse :

- Sous les titres de sections principales
- Comme separateur dans les cartes de services premium
- Comme indicateur de l'element actif dans la navigation

## 5. Traitement des images

### Photographies

Toutes les photographies utilisees sur le site subissent le traitement suivant :

1. **Desaturation partielle** : Saturation reduite a 70-80% de l'original
2. **Overlay Navy** : `#0C1B3A` en mode multiply a 10-15% d'opacite
3. **Contraste** : Legerement augmente (+5-10%)

Ce traitement cree une coherence visuelle sur toutes les images et renforce la tonalite serieuse de la marque.

### Images hero

Pour les heros de page, le traitement est plus prononce :

- Overlay gradient : de `#0C1B3A` a 70% (gauche) vers transparent (droite)
- Permet de placer du texte blanc lisible sur la partie gauche de l'image

### Portraits de l'equipe

- Fond neutre uniforme (gris clair `#E8ECF1` ou bleu tres pale)
- Cadrage serre (epaules et tete)
- Forme : cercle ou rectangle avec border-radius 8px
- Pas de filtre excessif, visages naturels

## 6. Disposition des pages cles

### Page d'accueil

La page d'accueil est structuree en entonnoir :

1. **Hero statement** : Phrase d'impact + 2 CTAs (fond navy avec overlay image)
2. **Problem statement** : "Ce que la due diligence conventionnelle ne revele pas" (fond clair)
3. **Services overview** : Grille de 6 services cles avec icones (fond off-white)
4. **Geographic reach** : Carte stylisee Canada-Afrique avec marches (fond navy)
5. **Differentiators** : "Why Mbhidiya Intelligence" en 5 points (fond clair)
6. **Process teaser** : Les 5 etapes en timeline horizontale (fond off-white)
7. **CTA final** : "Request an Intelligence Consultation" (fond navy gradient)
8. **Footer** : Contact, liens, legal (fond near-black)

### Pages de services

Chaque page de service suit la meme structure :

1. **Hero** : Titre percutant + sous-titre descriptif (fond navy)
2. **Problem statement** : Pourquoi ce service existe (fond clair)
3. **What we examine** : Liste structuree des domaines d'investigation (fond off-white)
4. **Use cases** : Situations types avec icones (fond clair)
5. **Deliverable** : Ce que le client recoit (fond navy)
6. **CTA** : "Discuss your intelligence requirement" (fond navy gradient)

## 7. Responsive design

### Breakpoints

| Nom          | Largeur       | Colonnes | Gouttiere |
| ------------ | ------------- | -------- | --------- |
| **Mobile**   | 0 - 639px     | 4        | 16px      |
| **Tablette** | 640 - 1023px  | 8        | 20px      |
| **Desktop**  | 1024 - 1439px | 12       | 24px      |
| **Large**    | 1440px+       | 12       | 24px      |

### Adaptations mobiles

- Le hero passe en pleine largeur avec overlay gradient vertical (haut vers bas)
- Les grilles de services passent en une colonne
- La navigation se replie dans un menu hamburger avec fond navy plein ecran
- Les sections fond sombre conservent leur traitement (important pour le rythme visuel)
- Le formulaire de contact s'adapte en pleine largeur
- Taille de texte de base : 16px minimum sur mobile (pas de text plus petit)

## 8. Accessibilite visuelle

| Critere                  | Standard                   | Implementation                                |
| ------------------------ | -------------------------- | --------------------------------------------- |
| Contraste texte/fond     | WCAG AA (4.5:1 min)        | Verifie sur toutes les combinaisons couleur   |
| Taille de texte minimale | 16px corps                 | 16px Inter Regular minimum                    |
| Focus visible            | Obligatoire                | Outline `#D4A017` 2px offset 2px              |
| Images                   | Alt text obligatoire       | Description contextuelle, pas decorative      |
| Liens                    | Distinguables sans couleur | Underline au hover + icone externe si externe |
| Formulaires              | Labels visibles            | Pas de placeholder-only labels                |
